# Kids Typing Games

A playful typing game for kids that runs in any web browser. Open `index.html` to play — no install needed.

## Games
0. 🖐️ **Finger Start** – for beginners: one letter at a time, with a color-coded keyboard and hands that show which finger to use. 8 levels that unlock one by one (the bumps, home row, top row, bottom row and more)
1. 🎈 **Balloon Pop** – type letters or words on balloons before they float away (home row, all letters, short words, or longer words). Pass all 20 levels to unlock the 👾 **Balloon Boss**: 60 balloons, angry waves and a super mad finish. The boss paces faster the angrier it gets, and you can only let 3 balloons get away
2. 🐘 **Jungle Animals** – type animal names before they leave the jungle
3. 🐙 **Sea World** – name sea creatures and plants as they drift by
4. 🐻‍❄️ **Arctic** – Santa, polar bears, northern lights and more
5. 🌍 **World Map** – type country names as they pop up on the map
6. 🗽 **USA Map** – type state names and big city names as they pop up in the right spot on the US map (states, cities, or both)

The World and USA maps load their outlines from the [jsvectormap](https://github.com/themustafaomar/jsvectormap) map files on a public CDN, so those two games need an internet connection.

## How it works
1. **Players** – pick, add or remove a player
2. **Adventure map** – all games sit along a winding road, each showing that player's progress; switch players or go home from here
3. **Game page** – choose options (where a game has them) and a level
4. **Play** – with buttons back to the levels or the map

## Features
- Multiple players with saved best scores and level progress (stored in the browser)
- A player named **Dad** has every game and level unlocked
- Games 1–6 have 5 levels by speed: Super slow, Slow, Medium, Fast, Super fast. Level 1 is always open; catch at least 8 of every 10 in a round to pass and unlock the next level
- 2-minute rounds with score, streak bonuses and sound effects
- On-screen keyboard guide that highlights the next key
- Works on desktop and phones/tablets, in light and dark mode
